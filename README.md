SpendWise AI

SpendWise AI is an AI-powered SaaS cost optimization dashboard designed to help organizations analyze AI tool subscriptions and identify unnecessary spending.

The platform audits popular AI tools such as ChatGPT, Claude, Cursor, Gemini, GitHub Copilot, and Windsurf by comparing current plans, team size, and usage patterns against smarter and more cost-effective alternatives.

SpendWise AI provides:

Intelligent optimization recommendations
Estimated monthly and yearly savings
Analytics dashboards
AI-generated audit summaries

This helps companies reduce unnecessary AI subscription costs and optimize their SaaS spending efficiently.

Setup Instructions
Clone the Repository
git clone <your-repository-url>
Frontend Setup
cd frontend
npm install
npm run dev

Frontend runs on:

http://localhost:5173
Backend Setup
cd backend
npm install
npm run dev

Backend runs on:

http://localhost:5000
Environment Variables
Backend .env

Create a .env file inside the backend folder:

MONGO_URI=your_mongodb_connection_string
PORT=5000
Frontend .env

Create a .env file inside the frontend folder:

VITE_API_URL=your_backend_url
Deployment Links
