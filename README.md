# SpendWise AI

AI spend auditing platform that helps startups optimize AI tool subscriptions and uncover cost-saving opportunities.

## Tech Stack

- React
- Express
- MongoDB
- Node.js
- TailwindCSS

## Features

- AI spend audit engine
- Personalized savings recommendations
- Shareable reports
- AI-generated summaries
- Lead capture system

## Current Features

- Dynamic AI spend form
- Tool-specific pricing plan selection
- Add/remove tool support
- Form persistence using localStorage
- React Router based audit flow
